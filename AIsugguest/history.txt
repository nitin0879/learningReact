how to add variables as color in tailwind?

You can add CSS variables as colors in Tailwind CSS using var(--variable-name).

There are two common approaches, depending on your Tailwind version.
1. Tailwind CSS v4 (recommended)

Define your CSS variables inside @theme:
css

@import "tailwindcss";

@theme {
  --color-primary: #6366f1;
  --color-secondary: #f97316;
  --color-background: #ffffff;
}

Now use them directly as Tailwind classes:

<div class="bg-primary text-secondary border-primary">
  Hello World
</div>

You can also use CSS variables:
css

:root {
  --primary: #6366f1;
}

<div class="bg-[var(--primary)]">
  Hello World
</div>

2. Tailwind CSS v3

Add variables to tailwind.config.js:
js

/** @type {import('tailwindcss').Config} */
export default {
  content: ["./src/**/*.{html,js,ts,jsx,tsx}"],
  theme: {
    extend: {
      colors: {
        primary: "var(--primary)",
        secondary: "var(--secondary)",
      },
    },
  },
  plugins: [],
};

Define your variables:
css

:root {
  --primary: #6366f1;
  --secondary: #f97316;
}

Use them:

<div class="bg-primary text-secondary">
  Hello World
</div>

You're close! The main issue is that you're trying to change a variable (color) directly instead of using React state to control the background color.

In React + Tailwind, you can do this using conditional rendering.
1. Corrected code (recommended)
jsx

import { useState } from "react";

function App() {
  const [username, setUsername] = useState("Guest");
  const [isDark, setIsDark] = useState(false);

  function Dark() {
    setIsDark(!isDark);
  }

  return (
    <section
      className={`${isDark ? "bg-black text-white" : "bg-white text-black"} min-h-screen`}
    >
      <input
        type="text"
        value={username}
        onChange={(e) => setUsername(e.target.value)}
      />

      <h1>Hello, {username}</h1>

      <button onClick={Dark}>
        {isDark ? "Light Mode" : "Dark Mode"}
      </button>
    </section>
  );
}

export default App;

2. How it works

The important part is:
jsx

className={`${isDark ? "bg-black text-white" : "bg-white text-black"}`}

This is a JavaScript ternary operator.

    If isDark is true, Tailwind applies bg-black text-white.

    If isDark is false, Tailwind applies bg-white text-black.

When you click the button:
jsx

setIsDark(!isDark);

React toggles the state and automatically re-renders the component.
3. Alternative: Using CSS variables

If you specifically want to use variables as colors:
jsx

<section
  style={{ "--bg-color": isDark ? "black" : "white" }}
  className="bg-[var(--bg-color)]"
>

This is useful when colors are dynamic or come from an API, theme settings, or user input.

My recommendation: Use conditional Tailwind classes for simple dark/light mode. Use CSS variables when you need dynamic colors.

Most likely, your button is rendering, but something is preventing it from receiving clicks, or the click handler isn't working as expected.

Looking at your previous code, try this corrected version:
jsx

import { useState } from "react";

function App() {
  const [isDark, setIsDark] = useState(false);

  return (
    <section
      className={`min-h-screen p-5 ${
        isDark ? "bg-black text-white" : "bg-white text-black"
      }`}
    >
      <button
        onClick={() => setIsDark((prev) => !prev)}
        className="rounded bg-blue-500 px-5 py-2 text-white cursor-pointer"
      >
        {isDark ? "Light Mode" : "Dark Mode"}
      </button>
    </section>
  );
}

export default App;

I found the issue! It's in your Dark() function.

Your current code:
jsx

function Dark() {
  if (isDark) {
    setIsDark(!isDark);
  }
}

You're only changing isDark when it's already true.

But your initial state is:
jsx

let [isDark, setIsDark] = useState(false);

So the if (isDark) condition is false initially, and nothing happens when you click the button.
Fix

Simply remove the if condition:
jsx

function Dark() {
  setIsDark(!isDark);
}

Or even better:
jsx

function Dark() {
  setIsDark((prev) => !prev);
}

Your complete corrected code
jsx

import { useState } from "react";

function App() {
